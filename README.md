# Street Sharkz Professional

Official site for Street Sharkz Professional. Static pages only.

Preview on your machine:

```
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/`.

The owner handbook is `HANDBOOK.md`: structure, videos, questions, the engine stub, and how to point `www.streetsharkz.com` later. There is no `CNAME` file yet.

`api.js` is a stub with no live endpoint. Fin replaces that file. Do not put an engine address in a page.
